# MyApp - Учебное приложение (Вариант 2)

## Описание
Простое Python-приложение, которое записывает историю HTTP-запросов в файл и отдает её пользователю. Версия: v0.9.0.

## Развертывание
1. Убедитесь, что установлен Docker и Docker Compose.
2. Скопируйте `env.example` в `.env` (при необходимости).
3. Запустите контейнер:
   ```bash
   docker compose up -d --build
